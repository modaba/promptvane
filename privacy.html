Privacy Policy - Prompt Vane Agent

Last updated: 1 November 2026

Prompt Vane Agent ("the app") is a private tool used only by the owner of the YouTube channel Prompt Vane to publish that channel's own videos and read that channel's own analytics. It is not offered to the public and has no other users.

YouTube API Services

The app uses YouTube API Services. By using it, the channel owner agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What information the app accesses

  • YouTube Data API: uploads the owner's videos with title, description, tags, thumbnail, audience setting, synthetic-media disclosure and the visibility the owner chooses; lists the channel's own uploads; reads public comments on the channel's own videos.
  • YouTube Analytics API: reads aggregate statistics for the owner's channel and videos (views, average view percentage, watch time, subscribers gained, likes, comments).
  • An OAuth authorization token for the owner's account.

How it is used, stored and shared

The data is used only to publish the owner's videos and to send the owner private performance reports (via the owner's own Telegram chat). It is stored only on the owner's computer, is never sold, and is never shared with any third party. Comments are read only in aggregate to find topics viewers ask about; no profiles of individual viewers are built. The app uses no cookies, no advertising and no third-party content.

Retention

Every 30 days or sooner (in practice daily) the app confirms it is still authorized and that each tracked video still exists on YouTube. Statistics for a video that was deleted, and all stored YouTube data if authorization is revoked or cannot be refreshed, are deleted. Other stored YouTube data is refreshed or deleted within 30 days.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions. After revocation, the app deletes all stored YouTube data within 7 days. To request deletion at any time, email the address below; deletion is completed within 7 calendar days.
